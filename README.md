# 🛰️ pytroll‑iac‑examples

Examples and reference implementations showing how to deploy Pytroll Helm charts using modern Infrastructure‑as‑Code tools such as Terraform/OpenTofu and ArgoCD.

This repository complements the Helm chart repository:

https://pytroll.github.io/pytroll-charts

It provides ready‑to‑use IaC snippets for:

- Deploying Pytroll components on Kubernetes
- Managing configuration through GitOps
- Integrating Pytroll workflows into cloud‑native environments
